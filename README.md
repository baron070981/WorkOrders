# WorkOrders

Android-приложение на Kotlin для регистрации и контролем
выполнения заявок на работы для электриков или сантехников

## 🛠️ Окружение
* **Android Studio:** Quail 4 (2026.1.4) или новее
* **JDK:**  25
* **Kotlin:**  2.3.10
* **AGP:**  9.4.0
* **Gradle:**  9.6.0

## 🚀 Технологии и стек
* **Язык:** Kotlin  2.3.10
* **Архитектура:**  MVVM
* **UI:**  XML 
* **База данных:**  Room  (`2.6.1`)

## 🛠️ Инструкция по сборке
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/baron070981/WorkOrders.git
   ```
2. Откройте проект в **Android Studio** (Ladybug или новее).
3. Дождитесь окончания Gradle Sync и запустите приложение на эмуляторе или реальном устройстве.
